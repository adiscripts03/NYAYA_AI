# ⚖️ NYAYA AI

> **जानीहि, रक्ष स्वाधिकारम्**  
> *"Know it. Protect your own rights."*

**NYAYA AI** is an AI-powered legal and civic empowerment platform designed to help everyday citizens understand and exercise their rights. Whether you are dealing with a workplace dispute, filing an RTI (Right to Information) application, or seeking guidance on consumer protection, Nyaya AI acts as your personal, accessible legal advisor.

---

## ✨ Features

- **🏛️ AI Legal Assistant:** A conversational AI interface that helps you understand your legal situation, breaks down complex legal jargon, and suggests actionable next steps.
- **📄 RTI Drafting Tool:** An interactive form that helps citizens instantly generate perfectly formatted Right to Information (RTI) applications.
- **📚 Civic Rights Knowledge Base:** Quick access to information regarding tenant rights, consumer protection, workplace disputes, and government welfare schemes.
- **🎨 Premium UI/UX:** A stunning, cinematic user interface built with modern web design principles, featuring the classical Lady of Justice.

---

## 💻 Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Vanilla CSS (Custom Design System)
- **Icons:** Lucide React
- **Typography:** Playfair Display & DM Sans

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/adiscripts03/NYAYA_AI.git
   cd NYAYA_AI
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
